# Bob — Tristan\'s personal AI companion

Single-file browser app. Works on **GitHub Pages**.

## Deploy (GitHub Pages)

1. Create a new repository (or open an existing one).
2. Upload **`index.html`** to the root of the repo (this file).
3. GitHub → **Settings** → **Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (or `master`) → `/ (root)`
4. Open the site URL (must be **https://**).

## First use

- Say `help`, `status`, `health check`
- Optional: Settings → free API key (Groq / Gemini / OpenRouter / xAI Grok)

## Icon

Bob uses a green **smile face** icon (favicon + in-app logo).

## Privacy

Memory stays in your browser `localStorage` unless you export JSON.
